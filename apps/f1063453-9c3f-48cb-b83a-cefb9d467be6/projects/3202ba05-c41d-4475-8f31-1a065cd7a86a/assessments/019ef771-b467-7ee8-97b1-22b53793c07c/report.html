Explanation

检测到同步 API 使用情况。

与本地环境相比，使用同步 API 可能会导致 Azure 中出现更多性能问题，因为存在不同的延迟配置文件。请考虑采用异步代码模式。

在负载过重的系统（尤其是在 I/O 非常大的情况下），使用异步模式可以提高整体吞吐量和性能。异步 API 使一小部分线程池能够管理数千个并发请求，而无需等待阻止调用。线程可以处理另一个请求，而不是等待长时间运行的同步任务完成。相反，大量的同步阻塞调用可能会导致线程池匮乏并降低响应时间。

请参阅下面的链接，了解有关异步编程的详细信息。
